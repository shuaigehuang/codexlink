# 第四步：Wails 电脑端控制台

日期：2026-11-12

## 目标

把已验证的 Codex 与 magpie 能力做成可运行的 Windows 桌面程序，界面接近 magpie 的深色控制台风格。

## 已完成

- 建立 Wails 3.1.0 桌面项目。
- 完成总览页、会话页、Magpie 页、设备配对页、运行日志页和设置页。
- 接入真实 Codex 历史会话，支持会话搜索、消息查看和命令记录展开。
- 接入真实 magpie 状态、Provider 与余额读取。
- 接通会话指令输入框和发送按钮。
- 添加应用图标、EXE 版本信息和最小窗口尺寸。
- 加入组件诊断摘要和密钥自动脱敏说明。
- 中继、手机配对和 Magpie 密钥写入明确标记为后续步骤，不展示虚假状态。

## 修复的问题

Codex `app-server` 在未提供 `turnId` 时读取整线程条目会直接退出。现在改为先分页读取轮次，再按每个 `turnId` 读取条目，并在进程异常后自动重建连接。
